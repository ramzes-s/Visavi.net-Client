# Правила проекта Visavi.net Client

## Git & GitHub Workflow

- **Целевой репозиторий**: Все обновления проекта отправляются в репозиторий `https://github.com/ramzes-s/Visavi.net-Client.git` (ветка `main`).
- **Подтверждение коммита и push**: При завершении любых редактирований или изменений файлов в проекте агент **ОБЯЗАН** перед созданием коммита и отправкой на GitHub:
  1. Перечислить список всех измененных, добавленных и удаленных файлов.
  2. Указать целевой репозиторий и ветку (`https://github.com/ramzes-s/Visavi.net-Client.git` -> `main`).
  3. Предложить вариант сообщения для коммита (commit message).
  4. Явно запросить разрешение у пользователя на выполнение `git commit` и `git push`.
- **Выполнение**: Выполнять `git commit` и `git push` строго **ПОСЛЕ** получения подтверждения от пользователя.
